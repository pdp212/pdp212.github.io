# Thư mục này chứa ảnh thumbnail cho từng dự án.
#
# QUY CÁCH ĐẶT TÊN FILE:
# Tên file khuyến nghị khớp với `id` của dự án trong data.js
# Ví dụ:
#   silver-swallows-brand-film.jpg
#   commercial-tvc-danang.jpg
#   motion-design-title-sequence.jpg
#   documentary-en-bac.jpg
#   graphic-design-visual-identity.jpg
#
# CÁCH SỬ DỤNG:
# Sau khi thêm ảnh vào thư mục này, mở file data.js
# và cập nhật trường `thumbnail` của dự án tương ứng:
#
#   thumbnail: 'assets/images/projects/ten-file.jpg',
#
# Kích thước khuyến nghị: 1280×720px (tỷ lệ 16:9), < 500KB
# Định dạng: .jpg hoặc .webp (tốt hơn về dung lượng)
