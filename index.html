Vibe Coding — Python & Manim

Kỹ thuật "Vibe Coding" với thư viện Python Manim để lập trình chuyển động toán học chính xác: data visualization, kinetic typography, và motion graphics kỹ thuật số — những hiệu ứng mà After Effects không thể tái hiện bằng tay.

enzyme_action.py — Manim Scene 
from manim import *

class CinematicTitle(Scene):
    def construct(self):
        title = Text(
            "PHAN ĐỨC PHÁT",
            font="Playfair Display",
            color="#C5A880"
        )
        line = Line(LEFT*3, RIGHT*3)
        line.set_color("#8E8E93")

        self.play(Write(title), run_time=2)
        self.play(Create(line))
        self.wait(1)
